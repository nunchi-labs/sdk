# Nunchi Wallet - Chrome Web Store Listing

## Name
Nunchi Wallet

## Short Description
Chrome wallet for Nunchi coins. Ed25519 or P-256 keys, nch addresses, window.nunchi. Not an EVM wallet.

## Full Description
Manifest V3 wallet for Nunchi chains. Not EVM and not EIP-1193. Not a substitute for an independent security audit.

**Features:**
- `window.nunchi` provider for dApp integration
- Ed25519 or P-256 (Secp256r1) key generation with CSPRNG
- Bech32 `nch` address format
- Signs via `nunchi-coins Transaction::sign`: transfer, create token, mint, burn, account policy
- Keystore: PBKDF2-SHA256 (210,000 iterations) + AES-GCM encrypted in `chrome.storage.local`

**Security:**
- Pages can only send: `REQUEST_CONNECTION`, `REQUEST_TRANSACTION`, `REQUEST_SIGN`, `GET_CHAIN_ID`, `GET_ACCOUNTS`, `DISCONNECT`
- Approval popup for connect, sign, and send
- Backup, export, and delete are privileged (extension page only)

**Network:**
- Default RPC: http://localhost:8545
- User can configure remote RPC. Remote hosts require optional host permission at save time.
- Onboarding discloses that keys stay on device, passwords cannot be recovered, and the software is unaudited.

## Images

Chrome Web Store listing images (upload these in the dashboard; they are not inside the zip):

- Store icon: `store/icons/store-icon-128.png` (128x128, 16px padding)
- Small promo tile: `store/images/promo-440x280.png`
- Screenshots (1280x800):
  - `store/images/screenshot-onboarding.png`
  - `store/images/screenshot-home.png`
  - `store/images/screenshot-approve.png`

These files are generated by `npm run icons` (Chromium headless). Source HTML is in `store/listing/`. To recapture:

```bash
# if you have Chromium
chromium --headless --disable-gpu --window-size=440,280 \
  --screenshot=store/images/promo-440x280.png store/listing/promo.html
chromium --headless --disable-gpu --window-size=1280,800 \
  --screenshot=store/images/screenshot-onboarding.png store/listing/screenshot-onboarding.html
chromium --headless --disable-gpu --window-size=1280,800 \
  --screenshot=store/images/screenshot-home.png store/listing/screenshot-home.html
chromium --headless --disable-gpu --window-size=1280,800 \
  --screenshot=store/images/screenshot-approve.png store/listing/screenshot-approve.html
```
